# andydixon/tap

Homebrew tap.

```sh
brew install andydixon/tap/mapsize
brew install andydixon/tap/swaptop   # Linux only
brew install andydixon/tap/dockertop # Linux only
brew install --cask andydixon/tap/nexusterminal   # Nexus Terminal, macOS
```

On Linux, Nexus Terminal is in the apt, dnf and pacman repository at
[repo.dixon.cx](https://repo.dixon.cx) as `nexusterminal`.
